# Listener profile template

Use one file per reusable listener profile. Use the same fields to capture the live wildcard.

- **Name and situation.** Who is listening and when?
- **News needs.** Which decisions, priorities, or questions should the briefing help with?
- **Relevant topics.** Which topics deserve more attention and what makes a story relevant?
- **Familiarity.** What can the briefing assume and which terms need explaining?
- **Depth and length.** How much context is useful and how much time does the listener have?
- **Selection example.** From the same day's coverage, which story would this listener hear first and why?
