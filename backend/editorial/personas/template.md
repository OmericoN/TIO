# Host persona template

Copy this file for each host and use the host's stable slug as the filename.

## Identity

- Display name and slug
- One sentence on the host's role in the briefing
- Four to six traits that describe how the host sounds

## Delivery

- Describe the host's character and relationship with the listener in one paragraph.
- Specify pace, sentence length, vocabulary, how to explain numbers, and how to attribute sources aloud.
- Describe how the host asks a clarifying question, reports research progress, and handles uncertainty.

## Sample lines

Write a short opening, a transition, and a line that acknowledges uncertainty. Use synthetic facts for any examples committed to Git. Follow the [editorial framework](../framework.md) for sourcing and verification.
