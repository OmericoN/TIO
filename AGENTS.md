# Project guidance

Read the [project brief in README.md](README.md#project-brief) before making product, pipeline, or demo decisions. It records the official judging requirements, the team's concept, and the decisions still open.

- Keep the core path intact: group multilingual coverage into stories, build a distinct English audio briefing for each listener profile, and link every spoken claim and number to its source article. Keep the active segment's supporting source visible during playback.
- Keep listener profiles separate from presentation modes. Use the organizer profiles for the demo, and design the briefing pipeline to accept the live wildcard profile.
- Account for cost across the full dataset and at 10× volume. Keep Newstex event data out of Git and delete it after the hackathon.
